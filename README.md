## ✨ Features & Highlights

- 🌌 **Interactive Background**: Animated canvas with connecting grid nodes and particle physics.
- ⚡ **Dynamic Hero Section**: Typing animation highlighting core roles and specialization.
- 💻 **Interactive Terminal Emulator**: Built-in CLI terminal allowing visitors to run commands like `help`, `skills`, `projects`, `whoami`, and `contact`.
- 🗂️ **Categorized Project Showcase**: Dynamic filtering for Mobile Apps, Web Applications, and Backend/Architecture.
- 📊 **Animated Skill Metrics**: Visual progress indicators for languages, frameworks, and database architecture.
- 📬 **Glassmorphism Contact Form**: Interactive feedback UI with custom toast notification alerts.

## 🛠️ Featured Projects

### 📱 1. AgriScan Mobile App
- **Overview**: An AI-powered agricultural mobile app enabling farmers to detect crop diseases via leaf scan analysis and obtain treatment solutions.
- **Tech Stack**: Flutter, Python, CNN (Convolutional Neural Networks), Multilingual Support (English, Hindi, Kannada).

### 🔍 2. Legal Search System
- **Overview**: An intelligent legal document platform with PDF text extraction, user authentication, and AI-driven document search.
- **Tech Stack**: Python, OCR, SQL, PDF Parsing Engine.

### 📐 3. Database & System Architecture
- **Overview**: Comprehensive collection of entity-relationship diagrams (ERD), Data Flow Diagrams (DFD), and relational SQL database schemas.
- **Tech Stack**: SQL, PostgreSQL, Systems Design.
